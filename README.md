# sisonke-marketplace

A full-stack PHP/MySQL marketplace web application where users can buy, sell, and discover products. Built with vanilla PHP, MySQL, HTML, CSS, and JavaScript — no frameworks.

## Features
### Buyers
- Browse products by category
- Search and filter listings
- Add products to cart
- Checkout with PayFast (sandbox)
- View order history

### Sellers
- Create, edit, and delete product listings
- Manage stock levels
- Track incoming orders and update their status

### Admin Panel
- Dashboard with live stats (users, products, orders)
- User management — suspend, ban, promote, reset passwords
- Product moderation — approve, reject, or flag fraudulent listings
- Order management — update order statuses
- Reports and analytics with Chart.js
